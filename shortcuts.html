Your lighting, modes and shortcuts in one place. Hold Fn while pressing the listed key.

This page describes the supplied VIA keymap. Remappings saved in VIA can override it. It is a reference only: use the physical keyboard to try the shortcuts.

Color presets: red → orange → yellow → green → cyan → blue → purple. The starting color depends on saved settings. Color changes are easiest to see with the solid-color effect.

Reset: hold Fn + ' (apostrophe, beside Enter) for over 3 seconds. The code flashes the keys three times, enables them and restores Cycle Left Right, blue hue, brightness 48 and speed 32. This resets key lighting, not the whole keyboard.

Mode cycle

Rainbow → Off → Single color → Breathing → Rainbow.

Color cycle

Red → Green → Blue → Yellow → Magenta → Cyan → White → Special color mode → Red.

The special step sends mode 0x13 when in single-color mode; its visual behavior depends on the controller.

Brightness & speed

Brightness cycles through five levels, including off. Speed cycles through four levels. Color is easiest to test in single-color mode.

Quick lighting check

  1. Hold Fn + ' for over 3 seconds to reset and enable key lighting.
  2. Try Fn + ↓ and Fn + ↑ for brightness.
  3. Try Fn + Backspace for effects, then Fn + ; for color.
  4. For side lights, cycle Fn + U to single color, then try Fn + I and Fn + O.

Flashing reminder

No bootloader shortcut is assigned in this keymap. In VIA, temporarily assign a key to Reset / QK_BOOT (raw keycode 0x7C00), then press it while QMK waits to flash. Save your VIA layout before replacing a mapping.

Esc held during a fresh startup triggers Bootmagic and clears saved EEPROM settings. USB unplugging may not restart the board because it has a battery.
